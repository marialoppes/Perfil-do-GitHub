## 🚀 Projetos

Aqui estão alguns dos projetos que desenvolvi durante minha graduação:

### 🎮 Jogo da Forca

Jogo desenvolvido em Python e executado pelo terminal, utilizando funções, listas, conjuntos, estruturas condicionais e estruturas de repetição.

### 📦 Sistema de Estoque

Sistema simples de controle de estoque desenvolvido em Python, permitindo visualizar produtos e registrar entradas e saídas utilizando dicionários.

### 🌡️ Conversor de Temperatura

Programa desenvolvido em Python para converter temperaturas de Celsius para Fahrenheit, praticando entrada de dados, conversão de tipos e operações matemáticas.

### 🔢 Cálculo de Fatorial

Projeto introdutório desenvolvido em Python utilizando a biblioteca `math` para calcular o fatorial de um número informado pelo usuário.
